# medical — 8개 타입

접수·문진·결과·청구·동의의 용도를 구분한다. 증상·응답·관찰·검사·행정 상태를 구체적으로 쓰되 해당 문서의 확인 범위를 넘어 진단·처방·치료 성공을 창작하지 않는다.

## registration — 진료 접수서

- 작성자: 접수 담당자
- 독자: 진료 담당자·환자
- 작성 관점: `staff_record`
- 당사자 역할: 환자:진료 대상 / 보호자:대리 접수와 확인의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 접수 정보 | 항목명: 확정된 값 또는 상태 | 방문 일시·진료과·초진 또는 재진 / 예약 여부와 실제 도착 시점 |
| 2 | 내원 사유 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 주증상과 시작 시점 / 변화 양상·일상 영향 |
| 3 | 기존 자료와 확인 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 이전 진료자료의 종류·시점·전달 상태 / 접수 질문과 환자 응답 |
| 4 | 접수 결과 | 항목명: 확정된 값 또는 상태 | 확인한 진료 요청과 전달 사항 / 접수 완료·대기 상태와 다음 안내 |

**상황별 포함·제외:** 초진은 시작 경위와 기존 자료 유무를, 재진은 지난 방문 후 변화를 기록한다. 보호자가 없으면 대리 동의를 만들지 않으며 확정 진단은 접수 내용에서 추정하지 않는다.

**완성 기준:** 진료자가 내원 이유·증상 경과·자료 전달 상태를 알 수 있고 개인정보 처리 설명이 본문을 대체하지 않는다.

| 선택 상황 ID | 상황 | 포함 | 제외 |
| --- | --- | --- | --- |
| `initial` | 초진 접수 | 증상 시작·변화·기존 자료 유무 | 이 기관의 이전 진료 결과를 전제로 한 서술 |
| `followup` | 재진 접수 | 지난 방문 이후 변화·자료 인계 | 초진이라는 동시 기재 |

## questionnaire — 문진표

- 작성자: 환자
- 독자: 문진을 확인하는 의료진
- 작성 관점: `patient_response`
- 당사자 역할: 환자:증상과 병력 응답의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 현재 증상 | 질문과 구체적인 응답을 짝지어 작성 | 시작 시점·빈도·강도에 대한 질문과 답 / 악화·완화 조건과 기능 제한 |
| 2 | 과거력 | 질문과 구체적인 응답을 짝지어 작성 | 기저질환·수술·치료 경험과 현재 상태 / 해당 없음 또는 모르는 항목의 구분 |
| 3 | 약물과 알레르기 | 질문과 구체적인 응답을 짝지어 작성 | 복용약 종류·주기·복용 목적 / 알레르기 대상·반응·발생 경험 |
| 4 | 생활습관 | 질문과 구체적인 응답을 짝지어 작성 | 수면·식사·활동의 구체 패턴 / 최근 변화와 추가로 알릴 사항 |

**상황별 포함·제외:** 복용약이 없으면 없음으로 기록하고 약명이 불확실하면 확인 필요로 남긴다. 증상 응답만으로 확정 진단이나 처방을 붙이지 않는다.

**완성 기준:** 각 질문에 실질 응답이 있고 미확인·없음이 구별되며 증상·약물·알레르기 사이의 서술이 모순되지 않는다.

## health_checkup — 건강검진 문진

- 작성자: 수검자
- 독자: 검진 담당 의료진
- 작성 관점: `patient_response`
- 당사자 역할: 수검자:검진 문진의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 검진 배경 | 항목명: 확정된 값 또는 상태 | 검진 목적·이전 검진 시점 / 현재 관리 중인 건강 문제 |
| 2 | 가족력·과거력 | 질문과 구체적인 응답을 짝지어 작성 | 가족 관계별 확인된 질환과 모르는 범위 / 본인 치료·추적 검사 이력 |
| 3 | 생활습관 | 질문과 구체적인 응답을 짝지어 작성 | 흡연·음주 빈도와 양 및 변화 시점 / 운동 종류·시간·주기와 수면 |
| 4 | 추가 확인 | 항목명: 확정된 값 또는 상태 | 이전 검진에서 추적하던 항목 / 직장검진 여부와 관련 노출·확인 요청 |

**상황별 포함·제외:** 비흡연·비음주이면 없음으로 기재한다. 직장검진일 때만 업무 노출을 다루며 문진표에 검사 결과 수치를 창작하지 않는다.

**완성 기준:** 생활습관에 양·빈도·기간이 있고 가족력과 본인 병력이 분리되며 이전 추적 상태가 확인된다.

## payment — 수납·영수 접수

- 작성자: 수납 담당자
- 독자: 환자·회계 담당자
- 작성 관점: `official_record`
- 당사자 역할: 환자:진료비 납부의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 수납 대상 | 항목명: 확정된 값 또는 상태 | 진료일·수납일·대상 서비스 / 청구 범위와 납부 상태 |
| 2 | 진료비 내역 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 항목별 수량·단가·금액 / 급여·비급여·본인부담 구분 |
| 3 | 정산 계산 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 총액·기납부액·조정액·잔액 / 납부 수단별 금액과 처리 시점 |
| 4 | 영수 및 확인 | 항목명: 확정된 값 또는 상태 | 결제 승인·취소·재결제 상태 / 잔여 납부액과 확인 사항 |

**상황별 포함·제외:** 취소·재결제가 있으면 시간순 금액 변화를 표시한다. 일괄 납부면 없는 환급이나 보험 지급을 추가하지 않는다.

**완성 기준:** 항목 합계와 본인부담·기납부·잔액이 맞고 실제 수납 상태를 구별할 수 있다.

## insurance_claim — 실손의료보험 청구서

- 작성자: 보험금 청구인
- 독자: 보험금 심사 담당자
- 작성 관점: `applicant_form`
- 당사자 역할: 피보험자:진료 대상 / 청구인:대리 또는 본인 청구 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 청구 개요 | 항목명: 확정된 값 또는 상태 | 청구인·피보험자의 역할 관계 / 진료 기간과 청구 사유 |
| 2 | 진료 및 비용 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 진료일별 치료 항목·비용 / 영수증·세부내역의 금액 대조 |
| 3 | 청구 산정과 자료 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 청구금액·기수령액·이번 요청액 / 첨부자료별 입증 사실과 누락 여부 |
| 4 | 지급 요청과 확인 | 항목명: 확정된 값 또는 상태 | 지급 대상과 요청 범위 / 접수·보완·심사 중 현재 상태 |

**상황별 포함·제외:** 본인 청구면 대리 위임을 만들지 않고 대리 청구면 권한·관계를 확인한다. 청구액을 승인된 보험금으로 표현하지 않는다.

**완성 기준:** 치료·영수증·청구액이 연결되고 청구인과 피보험자의 정보·권한·심사 상태가 일관된다.

## telemedicine_consult — 원격 진료 상담 기록지

- 작성자: 상담 의료진
- 독자: 환자·후속 진료 담당자
- 작성 관점: `clinician_record`
- 당사자 역할: 환자:상담 증상과 경과의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 상담 개요 | 항목명: 확정된 값 또는 상태 | 일시·상담 방식·상담 목적 / 초회 또는 후속 상담 구분 |
| 2 | 증상 문답 | 질문과 구체적인 응답을 짝지어 작성 | 증상 경위·강도·변화에 대한 4쌍 이상의 문답 / 이전 조치와 반응을 확인하는 4쌍 이상의 문답 |
| 3 | 관찰과 한계 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 원격으로 확인한 사실 / 직접 진찰 없이는 확인할 수 없는 사항 |
| 4 | 안내와 확인 | 질문과 구체적인 응답을 짝지어 작성 | 관찰에 근거한 후속 진료·확인 안내 / 환자의 이해 확인 질문과 답변 |

**상황별 포함·제외:** 후속 상담이면 지난 안내 이후 변화를 확인한다. 원격 관찰만으로 검사 결과나 확정 진단·치료 성공을 만들지 않는다.

**완성 기준:** 8쌍 이상의 문답이 서로 다른 정보를 제공하며 관찰 한계와 후속 확인 내용이 분명하다.

**상황별 포함·제외:** 이전 기록이 없으면 추세를 단정하지 않는다. 참고범위 이탈을 곧바로 확정 질환으로 바꾸지 않는다.

**완성 기준:** 수치·단위·참고범위·판정이 일치하고 종합소견과 추적 항목이 실제 결과에 근거한다.

| ---: | --- | --- | --- |

**완성 기준:** 처치 목적·대안·위험·질문·동의 범위가 있고 결과 보장이나 포괄적 무제한 동의를 쓰지 않는다.
