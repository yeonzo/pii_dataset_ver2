# legal — 7개 타입

작성자의 직접 경험·상대방 주장·증거·추정을 구분한다. 일시별 경위와 쟁점별 근거를 작성하고 법조문·책임·승소를 임의 확정하지 않는다.

## incident_report — 사건 경위서

- 작성자: 사건 당사자
- 독자: 사건 확인·처리 담당자
- 작성 관점: `first_person_reporter`
- 당사자 역할: 보고자:직접 경험한 사건의 진술인 / 상대방:사건의 다른 당사자 / 목격자:관찰 범위가 있는 참고인

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 작성 취지와 배경 | 항목명: 확정된 값 또는 상태 | 사건 종류·일시·장소 / 진술인의 참여 경위 |
| 2 | 시간순 경과 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 사건 전·중·후의 행동과 관찰 / 각 시점의 상대방 행동 |
| 3 | 확인 자료 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 자료별 확인 가능한 사실 / 직접 경험·전언·추정의 구분 |
| 4 | 결과와 확인 요청 | 항목명: 확정된 값 또는 상태 | 발생한 영향과 취한 조치 / 미확인 사항과 요청 범위 |

**상황별 포함·제외:** 직접 보지 못한 부분은 전언·추정으로 구별한다. 사고 원인이나 책임을 자료 없이 확정하지 않는다.

**완성 기준:** 시간순 경위와 자료가 대응하고 진술인의 관찰 한계 및 현재 상태를 알 수 있다.

## legal_consultation — 법률 상담 기록

- 작성자: 법률 상담 기록자
- 독자: 상담 의뢰인·후속 담당자
- 작성 관점: `staff_record`
- 당사자 역할: 의뢰인:사실·질문 제공자 / 상대방:분쟁 상대 / 참고인:별도 관찰 자료의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 상담 개요 | 항목명: 확정된 값 또는 상태 | 상담 목적과 의뢰인의 질문 / 사건 유형과 현재 진행 단계 |
| 2 | 제공된 사실 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 의뢰인이 설명한 시간순 경위 / 상대방 주장과 다투는 부분 |
| 3 | 자료와 쟁점 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 자료별 확인 가능한 조건 / 쟁점별 확인된 사실과 부족한 정보 |
| 4 | 상담 내용과 후속 | 항목명: 확정된 값 또는 상태 | 설명한 절차·선택지와 전제 / 추가 준비 자료·후속 일정 |

**상황별 포함·제외:** 소송 전후 상태에 맞는 절차를 다룬다. 없는 법조문을 만들거나 승소·책임을 단정하지 않으며 상담 의견과 사실을 구분한다.

**완성 기준:** 질문→자료→쟁점→조건부 안내가 연결되고 확인되지 않은 전제가 드러난다.

## complaint_filing — 고소·고발장

- 작성자: 피해 신고인
- 독자: 사건 접수·수사 담당자
- 작성 관점: `first_person_reporter`
- 당사자 역할: 신고인:피해와 행위의 진술자 / 상대방:조사 요청 대상 / 목격자:관찰 자료의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 신고 취지 | 항목명: 확정된 값 또는 상태 | 조사를 요청하는 행위 / 당사자 관계와 사건 범위 |
| 2 | 행위와 피해 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 행위별 일시·장소·방법 / 행위와 피해 사이의 연결 |
| 3 | 증거 목록 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 자료 종류·작성 또는 확보 시점 / 각 자료로 입증할 사실과 한계 |
| 4 | 조사 요청과 확인 | 항목명: 확정된 값 또는 상태 | 미확인 사항과 구체적인 조사 요청 / 진술 확인과 첨부자료 목록 |

**상황별 포함·제외:** 직접 피해와 전해 들은 피해를 구분한다. 법적 판단이나 형량을 확정하지 않고 계획에 없는 인물을 피신고인으로 추가하지 않는다.

**완성 기준:** 대상 행위·피해·증거·조사 요청이 대응하고 단순 불만이나 법률 설명으로 대체되지 않는다.

## damage_claim — 손해배상 청구서

- 작성자: 손해배상 청구인
- 독자: 상대방·분쟁 처리 담당자
- 작성 관점: `first_person_claimant`
- 당사자 역할: 청구인:손해와 배상 요구의 주체 / 상대방:배상 요구 대상 / 참고인:피해 경위의 확인자

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 청구 취지 | 항목명: 확정된 값 또는 상태 | 청구 대상과 요청 총액 / 손해 발생의 일시·원인 |
| 2 | 손해 내역 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 항목별 수량·단가·금액 / 실제 지출과 견적의 구분 |
| 3 | 근거와 정산 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 자료별 입증 항목 / 기지급액·상계액·잔여 청구액 |
| 4 | 이행 요청 | 항목명: 확정된 값 또는 상태 | 지급 또는 보완 요청 기한 / 이견 사항과 협의 방법 |

**상황별 포함·제외:** 미확정 치료·수리비는 추정과 확정 지출을 구분한다. 지급받은 금액을 다시 청구액에 더하지 않는다.

**완성 기준:** 원인과 손해 항목이 연결되고 합계·기지급·잔액 계산 및 요청 기한이 명확하다.

## witness_statement — 목격자 진술서

- 작성자: 목격자
- 독자: 사건 조사·심리 담당자
- 작성 관점: `first_person_witness`
- 당사자 역할: 목격자:직접 관찰 진술자 / 사건 당사자:관찰된 행위의 주체 / 상대 당사자:관찰된 다른 행위의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 목격 조건 | 항목명: 확정된 값 또는 상태 | 목격 시각·위치·거리 / 조명·시야·관찰을 방해한 요인 |
| 2 | 관찰 순서 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 사건 전·중·후 직접 본 행동 / 직접 들은 내용과 발화 주체 |
| 3 | 기억과 자료 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 기억을 보완하는 메모·자료 / 기억과 기록의 일치·불일치 |
| 4 | 관찰 한계와 확인 | 항목명: 확정된 값 또는 상태 | 보거나 듣지 못한 범위 / 추정·정정한 부분과 이유 |

**상황별 포함·제외:** 전언은 직접 목격과 분리한다. 멀리서 보았거나 시야가 가려진 경우 확인할 수 없는 세부사항을 단정하지 않는다.

**완성 기준:** 관찰 조건과 진술의 상세 수준이 맞고 직접 관찰·전언·추정·기억 공백이 구분된다.

## police_statement — 경찰 진술서

- 작성자: 조사 기록자와 진술인
- 독자: 사건 조사 담당자·진술 확인자
- 작성 관점: `interview_record`
- 당사자 역할: 진술인:질문에 답하는 사건 당사자 / 상대방:진술에서 다루는 당사자 / 목격자:확인된 참고인

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 조사 개요 | 항목명: 확정된 값 또는 상태 | 조사 일시와 진술인 역할 / 사건 참여 경위와 진술 범위 |
| 2 | 사건 문답 | 질문과 구체적인 응답을 짝지어 작성 | 시간순 행동·대상·장소를 확인하는 질문과 답 / 직접 경험과 전언을 구분하는 응답 |
| 3 | 자료 제시 문답 | 질문과 구체적인 응답을 짝지어 작성 | 제시 자료와 그에 대한 확인 답변 / 기존 진술과 차이가 있는 부분 |
| 4 | 정정과 확인 | 항목명: 확정된 값 또는 상태 | 정정한 내용과 정정 이유 / 읽고 확인한 범위와 추가 진술 |

**상황별 포함·제외:** 자료를 제시하지 않았으면 자료 확인 응답을 만들지 않는다. 모른다는 답변을 자백이나 확정 사실로 바꾸지 않는다.

**완성 기준:** 질문과 답변이 실제로 대응하고 자료 제시·정정·최종 확인의 순서를 추적할 수 있다.

## mediation_application — 분쟁 조정 신청서

- 작성자: 조정 신청인
- 독자: 조정 담당자·상대방
- 작성 관점: `first_person_applicant`
- 당사자 역할: 신청인:조정 요구의 주체 / 상대방:이견과 이행의 당사자 / 참고인:확인 자료의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 신청 취지 | 항목명: 확정된 값 또는 상태 | 분쟁 대상과 조정을 원하는 범위 / 당사자별 현재 요구 |
| 2 | 분쟁 경위 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 계약·행위·피해의 시간순 경과 / 쟁점이 발생한 구체 지점 |
| 3 | 쟁점과 자료 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 쟁점별 신청인·상대방 주장 / 증거와 미확인 사실 |
| 4 | 협의와 조정안 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 이전 제안·응답·결렬 이유 / 양보 범위·금액·이행 일정 |
| 5 | 확인과 요청 | 항목명: 확정된 값 또는 상태 | 합의 대상과 제외 사항 / 자료 제출·후속 회의 요청 |

**상황별 포함·제외:** 금전 조정은 산정 근거와 지급 일정을, 비금전 조정은 행위 범위와 완료 기준을 적는다. 제안한 조정안을 이미 성립한 합의로 표현하지 않는다.

**완성 기준:** 쟁점·양측 요구·자료·조정안이 연결되고 제안과 합의·이행 완료 상태가 분리된다.
