# career_education — 10개 타입

자기소개·경력·추천은 지정된 작성자의 실제 사례와 평가를 중심으로 쓴다. 학사 증명·신청은 기준일·학적·내역을 항목과 표로 작성한다. 모든 종류를 상담 기록으로 바꾸지 않는다.

## resume_form — 이력서

- 작성자: 지원자
- 독자: 채용 담당자
- 작성 관점: `applicant_form`
- 당사자 역할: 지원자:학력·경력·역량의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 지원 사항 | 항목명: 확정된 값 또는 상태 | 지원 직무 / 경력 수준과 지원 가능 시점 |
| 2 | 학력과 교육 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 최종 학력의 기간·과정·이수 내용 / 직무와 연결되는 교육 내용 |
| 3 | 경력과 프로젝트 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 수행 기간·담당 업무·사용 도구 / 프로젝트별 본인 기여와 결과 |
| 4 | 자격과 역량 | 항목명: 확정된 값 또는 상태 | 자격 취득 시기와 활용 경험 / 기술별 숙련 근거와 확인 가능한 산출물 |

**상황별 포함·제외:** 신입이면 학습·실습 사례를 쓰고 재직 경력을 창작하지 않는다. 경력직이면 실제 수행 업무를 우선한다. 한 인물에게 여러 학교·직장 엔티티를 추가하지 않는다.

**완성 기준:** 기간이 겹치거나 학력·경력 주체가 바뀌지 않으며 각 역량을 뒷받침하는 수행 사실이 있다.

## cover_letter — 자기소개서

- 작성자: 지원자
- 독자: 채용 심사자
- 작성 관점: `first_person_applicant`
- 당사자 역할: 지원자:경험과 지원 동기의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 지원 동기 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 지원 직무의 구체 과제 / 관심을 갖게 된 경험 |
| 2 | 문제와 역할 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 사례의 초기 상태와 제약 / 본인의 책임 범위 |
| 3 | 행동과 결과 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 선택한 방법과 대안 비교 / 실행 과정과 측정 가능한 결과 |
| 4 | 배운 점과 기여 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 실패·한계에서 바꾼 행동 / 입사 초기 기여 계획과 확인 지표 |

**상황별 포함·제외:** 신입은 학습·팀 과제도 근거로 사용한다. 성과를 수치화할 자료가 없으면 관찰 결과를 쓰고 임의의 매출·수상 실적은 붙이지 않는다.

**완성 기준:** 지원 동기와 행동 사례가 같은 직무로 연결되고 본인의 행동·결과·한계가 구별된다.

## career_statement — 경력기술서

- 작성자: 경력 지원자
- 독자: 채용 담당자·실무 면접관
- 작성 관점: `first_person_professional`
- 당사자 역할: 지원자:담당 업무와 기여의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 경력 개요 | 항목명: 확정된 값 또는 상태 | 담당 직무와 수행 기간 / 책임 범위와 협업 경계 |
| 2 | 프로젝트 개요 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 프로젝트 목표·기간·초기 지표 / 투입 도구와 제약 |
| 3 | 수행 내용 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 본인이 내린 결정과 실행 단계 / 장애 요인과 해결 과정 |
| 4 | 성과와 인계 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 결과 지표·측정 기간·비교 기준 / 재사용 산출물과 남은 과제 |

**상황별 포함·제외:** 공동 성과는 팀 전체 결과와 본인 기여를 구분한다. 이직 이력은 추가 직장 엔티티 없이 확정된 소속 범위에서만 전개한다.

**완성 기준:** 업무 나열에 그치지 않고 역할→실행→결과가 연결되며 수치의 기준과 기여 범위를 알 수 있다.

## job_application — 입사지원서

- 작성자: 지원자
- 독자: 인사 채용 담당자
- 작성 관점: `applicant_form`
- 당사자 역할: 신청인:채용 지원의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 지원 기본 사항 | 항목명: 확정된 값 또는 상태 | 지원 분야와 지원 구분 / 근무 시작 가능 시점 |
| 2 | 학력·경력 요약 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 최종 교육 과정과 직무 연관 내용 / 수행 기간·업무·역할 |
| 3 | 직무 경험 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 요구 역량과 연결되는 사례 / 본인 행동과 결과 |
| 4 | 지원 사유와 확인 | 항목명: 확정된 값 또는 상태 | 지원 분야 선택 이유 / 제출 자료와 확인·동의 범위 |

**상황별 포함·제외:** 신입이면 실습·과제 경험으로 기재하고 경력직이면 업무 실적으로 기재한다. 지원 대상 기관을 이전 직장으로 잘못 연결하지 않는다.

**완성 기준:** 지원 직무·경력 구분·사례·제출 의사가 일치하고 빈 양식이나 작성 요령이 아니다.

## recommendation — 추천서

- 작성자: 추천인
- 독자: 채용·입학 심사자
- 작성 관점: `first_person_recommender`
- 당사자 역할: 피추천인:평가 대상 / 추천인:직접 관찰하고 평가하는 사람

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 추천 취지와 관찰 관계 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 추천 목적과 지원 분야 / 관찰 관계·기간·빈도 |
| 2 | 관찰 사례 1 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 구체적인 과제와 어려움 / 피추천인의 행동·결과 |
| 3 | 관찰 사례 2 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 다른 과제 또는 협업 상황 / 갈등 대응·기여·관찰 결과 |
| 4 | 평가와 추천 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 두 사례가 뒷받침하는 강점 / 보완점과 추천 범위·명시적 추천 의사 |

**상황별 포함·제외:** 직접 관찰한 사실과 전해 들은 사실을 구분한다. 학업 추천은 학습·연구 사례를, 직무 추천은 업무 사례를 쓴다. 추천 요청 경위를 본문 중심으로 삼지 않는다.

**완성 기준:** 추천인이 말하고 두 사례의 행동·결과가 평가를 뒷받침하며 누구를 무엇을 위해 추천하는지 명확하다.

| 선택 상황 ID | 상황 | 포함 | 제외 |
| --- | --- | --- | --- |
| `employment` | 직무 역량 추천 | 업무 관찰 관계·기간 / 두 업무 사례의 행동·성과 | 추천 요청 사실만으로 구성한 경위서 |
| `academic` | 학업·연구 역량 추천 | 학습·연구 관찰 관계·기간 / 두 학업 사례의 행동·결과 | 근거 없는 취업 실적 |

## admission_application — 입학·편입 원서

- 작성자: 입학 지원자
- 독자: 입학 심사 담당자
- 작성 관점: `applicant_form`
- 당사자 역할: 지원자:학업계획 주체 / 보호자:미성년 지원의 확인자

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 지원 과정 | 항목명: 확정된 값 또는 상태 | 지원 구분과 과정 / 선택한 학문 분야와 지원 동기 |
| 2 | 선행 학습 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 이수 과목·실습·연구 경험 / 관련 과제와 학습 결과 |
| 3 | 학업 계획 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 학기별 학습 목표와 이수 계획 / 연구·실습 주제와 실행 방법 |
| 4 | 수행 여건과 확인 | 항목명: 확정된 값 또는 상태 | 학업 시간·자원 확보 계획 / 제출 자료와 확인 사항 |

**상황별 포함·제외:** 미성년·대리 확인이면 계획된 보호자 역할을 쓰고 성인 단독 지원이면 보호자 동의를 만들지 않는다.

**완성 기준:** 선행 학습과 지원 과정이 연결되고 학기별 계획이 구체적이며 지원자와 보호자의 의사가 구분된다.

| 3 | 증명 사실 | 항목명: 확정된 값 또는 상태 | 기준일 현재 재학 또는 졸업 상태 / 졸업일·학위 또는 재학 학기의 확인 |
| 4 | 발급과 확인 범위 | 항목명: 확정된 값 또는 상태 | 발급 목적·일자와 제출 용도 / 확인한 기록 범위와 제외 범위 |

**상황별 포함·제외:** 재학 증명에는 졸업 확정을 넣지 않고 졸업 증명에는 재학 중이라고 쓰지 않는다. 변동 이력이 없으면 없음으로 기재한다.

**완성 기준:** 기준일·학적 상태·과정·변동 내역이 일치하며 실제 증명 문구가 있고 홍보나 상담 서사가 없다.

| 2 | 신청 사유 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 지원 필요 또는 성취의 구체 경위 / 관련 활동 두 건과 증빙 |
| 3 | 학업·활용 계획 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 학업 목표와 실행 일정 / 지원금 항목별 금액·산정 근거 |
| 4 | 첨부와 확인 | 항목명: 확정된 값 또는 상태 | 자료별 입증 사항 / 지급 대상과 조건 확인 |

**상황별 포함·제외:** 성적형은 성취 근거를, 생활지원형은 비용·지원 필요를 중심으로 쓴다. 보증 조건이 없으면 보증 책임을 덧붙이지 않는다.

**완성 기준:** 장학 유형에 맞는 근거가 있고 사용 계획 합계·일정·학업 목표가 연결된다.

## leave_return — 휴학·복학 신청서

- 작성자: 학생
- 독자: 학사 담당자
- 작성 관점: `applicant_form`
- 당사자 역할: 학생:휴학 또는 복학 신청자

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 신청 구분 | 항목명: 확정된 값 또는 상태 | 휴학 또는 복학 중 한 구분 / 대상 학기와 현재 학적 상태 |
| 2 | 신청 사유 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 상태 변경의 경위와 시점 / 학업에 미치는 영향 |
| 3 | 일정 및 학사 처리 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 신청 기간과 처리 예정일 / 수강·등록금·장학 관련 확인 사항 |
| 4 | 이후 계획과 확인 | 항목명: 확정된 값 또는 상태 | 휴학 중 준비 또는 복학 후 이수 계획 / 제출 자료와 신청 의사 |

**상황별 포함·제외:** 휴학이면 중단 기간·복귀 계획을, 복학이면 복귀 학기·수강 준비를 쓴다. 같은 신청에서 휴학과 복학을 동시에 확정하지 않는다.

**완성 기준:** 신청 구분·기간·학적 상태가 일치하며 해당 학기의 구체적인 처리와 계획이 있다.

| 선택 상황 ID | 상황 | 포함 | 제외 |
| --- | --- | --- | --- |
| `leave` | 휴학 신청 | 중단 기간·사유·복귀 준비 | 이번 학기 복학 승인 완료 |
| `return` | 복학 신청 | 복귀 학기·수강·등록 준비 | 이번 학기 신규 휴학 신청 |
