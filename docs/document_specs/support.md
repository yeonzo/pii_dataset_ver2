# support — 8개 타입

실제 상담 기록으로 접수·고객 요구·증빙·담당자 확인·처리 상태를 구분한다. 고객의 주장과 검증 결과를 섞지 않는다. 담당자의 일반 업무 설명을 반복하지 않는다.

## complaint_product — 상품 민원 접수서

- 작성자: 고객지원 담당자
- 독자: 품질·처리 담당자와 고객
- 작성 관점: `staff_record`
- 당사자 역할: 고객:제품 불만 제기자

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 접수와 주문 | 항목명: 확정된 값 또는 상태 | 접수 일시·채널 / 제품 종류·구매 시점·수령 상태 |
| 2 | 결함과 영향 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 발생 조건과 관찰된 결함 / 고객의 사용·피해 범위 |
| 3 | 증빙과 조사 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 사진·영상·검사별 확인 사실 / 주장과 확인 결과의 차이 |
| 4 | 요청과 처리 | 항목명: 확정된 값 또는 상태 | 교환·수리·환불 중 고객 요구 / 결정 근거·현재 상태·후속 일정 |

**상황별 포함·제외:** 초기 불량이면 수령 직후 상태를, 사용 중 고장이면 사용 조건·기간을 확인한다. 검사가 끝나지 않았으면 제조상 결함을 확정하지 않는다.

**완성 기준:** 제품·결함·증빙·요청이 연결되고 조사 결과와 미확인 사항 및 다음 조치가 구분된다.

## complaint_service — 서비스 민원 접수서

- 작성자: 상담 담당자
- 독자: 서비스 운영 담당자와 고객
- 작성 관점: `staff_record`
- 당사자 역할: 고객:서비스 불이행 영향의 당사자

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 서비스 약속 | 항목명: 확정된 값 또는 상태 | 접수 시점·채널 / 약속된 범위·시간·요금 |
| 2 | 실제 이행과 불만 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 이행된 내용과 누락 사항 / 고객에게 발생한 영향 |
| 3 | 확인 경과 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 부서별 확인 시각과 자료 / 약속과 실제 이행의 대조 |
| 4 | 조정 결과 | 항목명: 확정된 값 또는 상태 | 고객 요구와 제안한 조치 / 수락 여부·잔여 문제·후속 일정 |

**상황별 포함·제외:** 지연이면 지연 시간과 영향, 미제공이면 누락 범위를 확인한다. 서비스 사건에 상품 회수·외관 검수를 넣지 않는다.

**완성 기준:** 약속과 실제 차이를 구체적으로 알 수 있고 완료·제안·미확인 상태가 섞이지 않는다.

## support_ticket — 고객지원 티켓

- 작성자: 기술지원 담당자
- 독자: 개발·운영 담당자와 요청자
- 작성 관점: `staff_record`
- 당사자 역할: 고객:오류를 경험한 사용자

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 환경과 증상 | 항목명: 확정된 값 또는 상태 | 제품·버전·실행 환경 / 기대 동작과 실제 오류 |
| 2 | 재현 절차 | 번호별 실행 순서와 그 단계의 확인 결과 | 입력·설정·행동 순서 / 발생 빈도와 정상 대조 조건 |
| 3 | 진단 기록 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 진단 시도 3건의 방법·결과 / 원인 가설을 지지·반박하는 관찰 |
| 4 | 조치와 남은 과제 | 항목명: 확정된 값 또는 상태 | 우회 방법과 검증 결과 / 미해결 범위·담당 역할·다음 확인 시점 |

**상황별 포함·제외:** 재현되면 조건을 고정하고 재현되지 않으면 수집할 로그·조건을 적는다. 검증 전 원인이나 해결 완료를 단정하지 않는다.

**완성 기준:** 다른 담당자가 절차를 따라 재현하거나 추가 조사할 수 있고 각 진단의 결과가 서로 다르다.

## refund_request — 환불 요청 처리 기록

- 작성자: 환불 상담 담당자
- 독자: 정산 담당자와 고객
- 작성 관점: `staff_record`
- 당사자 역할: 고객:결제·환불 요청의 주체

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 요청과 거래 | 항목명: 확정된 값 또는 상태 | 접수 채널·요청 일시 / 거래 대상과 결제 시점·금액 |
| 2 | 환불 사유와 경위 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 문제 발생과 고객 요청의 시간순 경위 / 환불 판단에 필요한 증빙 |
| 3 | 사실 확인 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 자료별 확인 내용과 미확인 사항 / 거래 유형에 맞는 처리 가능 조건 |
| 4 | 금액과 처리 상태 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 원결제액·공제액·환불액의 계산 / 취소 요청·승인·반환 중 현재 상태 |
| 5 | 후속 안내 | 항목명: 확정된 값 또는 상태 | 고객과 확인한 내용 / 남은 조치와 예상 확인 시점 |

**상황별 포함·제외:** 상품 반품이면 수령·회수·검수 상태를 포함한다. 구독 해지이면 해지 시점·이후 청구·이용 이력을 포함하고 제품 배송·회수·검수를 제외한다.

**완성 기준:** 환불 사유와 증빙이 연결되고 환불액 산식이 맞으며 요청·승인·실제 입금 상태가 명확하다.

| 선택 상황 ID | 상황 | 포함 | 제외 |
| --- | --- | --- | --- |
| `subscription` | 구독 해지 후 재청구 | 해지 요청·완료 시각과 이후 청구 / 이용 이력·취소 요청·환불 산정 | 실물 상품 배송·수령 / 제품 회수·외관 검수 |
| `goods` | 실물 상품 반품 환불 | 구매·수령과 반품 사유 / 회수·검수 상태와 비용·환불액 산정 | 구독 해지 / 정기결제 시스템의 재청구 |
| `service_cancel` | 예약 서비스 취소 환불 | 예약일·취소 시점·제공 여부 / 취소 조건·공제액·환불액 | 제품 배송·회수·검수 / 정기 구독 해지 |

## delivery_issue — 배송 문제 접수서

- 작성자: 배송 상담 담당자
- 독자: 물류 담당자·고객
- 작성 관점: `staff_record`
- 당사자 역할: 고객:수령 여부 확인의 당사자

| 순서 | 실제 항목명 | 표현 형식 | 반드시 채울 사실 |
| ---: | --- | --- | --- |
| 1 | 배송 접수 | 항목명: 확정된 값 또는 상태 | 주문 품목과 약속된 도착 시점 / 고객 문의 시점·요구 |
| 2 | 추적 내역 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 발송·이동·배달 상태별 시각 / 마지막 확인 위치와 상태 |
| 3 | 수령 사실 대조 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 배송 완료 표시와 고객 진술 / 사진·인수 기록·운송사 확인 결과 |
| 4 | 처리와 안내 | 항목명: 확정된 값 또는 상태 | 재배송·조사·대기 중 선택한 조치 / 다음 확인 시점과 담당 역할 |

**상황별 포함·제외:** 완료 표시와 미수령이 충돌하면 인수 증빙을 확인한다. 단순 지연이면 수령 완료나 분실을 확정하지 않는다.

**완성 기준:** 추적 이력과 고객 진술의 차이가 드러나고 확인된 상태를 근거로 후속 조치가 정해져 있다.

| 2 | 고장 경위 | 지정 화자의 연결된 서술; 사건·행동·근거·결과 | 증상 발생 조건·빈도 / 사용자가 시도한 점검과 결과 |
| 3 | 점검과 견적 | 항목별 내역과 대응 관계가 명확한 표·목록·문장 나열; 표 헤더는 필수가 아님 | 부위별 점검·관찰 결과 / 수리 항목·부품·공임·총액 |

**상황별 포함·제외:** 보증 내 무상이면 제외 사유 여부를 확인하고 유상이면 비용 동의를 기록한다. 점검 전 부품 교체 완료를 쓰지 않는다.

**완성 기준:** 증상→점검→수리 범위가 연결되고 견적 합계 및 동의·완료 상태가 일관된다.

**완성 기준:** 항목별 차액이 전체 이의 금액과 맞고 판단 근거 및 미확정 부분이 분리된다.
